# v0.9.5 / P0-5 — HTTP trailer limits and real RSS

Date: 2026-11-11. Branch `release/v0.9.5`, measured at `cf00c659` with the
P0-5 changes; this evidence file is part of the P0-5 commit. `Cargo.toml`
remains `0.9.4`; nothing was pushed, tagged, released or published.

## Objective

Close AUD-03/P0-5: a hostile or broken chunked origin must not keep a trailer
section open indefinitely, and the proxy must not accumulate an unbounded h1
`Vec` or h2/h3 `HeaderMap`. The limits must be enforced in h1, h2 and h3, the
refusal must be observable, normal trailers must keep working, and the memory
claim must come from a real binary run rather than an estimate.

## Contract

- A trailer section is refused when its complete wire lines, including CRLF,
  exceed **64 KiB**, or when it has more than **128 fields**. The byte limit
  is inclusive; the next byte is refused.
- The budget is checked before parsing or forwarding a line. A refused line is
  never forwarded.
- h1 request: `400` before the backend receives the 129th trailer.
- h1 response: if the head is already committed, close the exchange. A `502`
  cannot be fabricated after a `200` without buffering the streamed body.
- h2: `RST_STREAM` with `ENHANCE_YOUR_CALM`.
- h3: `H3_GENERAL_PROTOCOL_ERROR`; a reset may reach the client before the
  buffered response head, which is still an explicit cut.
- Normal 0–2 trailer responses remain unchanged.

## Real RSS measurement

The journey spawned the actual binary (`env!("CARGO_BIN_EXE_eqproxy")`), a
listener with gzip enabled and a real chunked origin. The origin sent a small
body followed by **100 000 trailers** of roughly 7.9 KiB. The child stayed
alive while `ps -o rss= -p <pid>` was sampled. Raw output:

```text
TRAILER_RSS baseline_kib=14048 peak_kib=18704 growth_kib=4656 budget_kib=65536 response_bytes=190 elapsed_ms=23
```

The measured growth is **4 656 KiB**, below the declared **64 MiB** budget.
The client received the committed response bytes (`response_bytes=190`) and
the connection was cut; the counter reached 1. This is a real execution, not a
model or an estimate.
